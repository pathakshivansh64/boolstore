# 📚 BookStore Web App

A fully functional BookStore web application built with **React**, featuring user authentication, book listings, cart functionality, and checkout.

---

## 🔧 Tech Stack

### Frontend
- React 19
- React Router DOM
- Axios
- Tailwind CSS
- Heroicons
- React Hot Toast
- Vite

> ⚠️ You don’t need to run the backend locally — it's already deployed. Just run the frontend to get started!
>
> ## 🚀 Deployment


- **Backend**: Express API – Deployed on [Render](https://bookstore-rop2.onrender.com)

---

## 🚀 How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/bookstore-app.git
cd bookstore-app/frontend

2. Install Dependencies
npm install

3. Start the Frontend
npm run dev

This will start the app at: http://localhost:5173
